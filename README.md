# Дзеркало розкладу УДУ — хмарний пакет

Система, що забезпечує доступ студентів і викладачів до розкладу занять
**навіть тоді, коли сервери університету вимкнені** (блекаут).

> 🚀 **Хочете одразу запустити сайт?** Вам сюди:
> **[ІНСТРУКЦІЯ-ЗАПУСКУ-САЙТУ.md](ІНСТРУКЦІЯ-ЗАПУСКУ-САЙТУ.md)** — детально,
> покроково, без програмування.

## Як це працює

```
nmc.udu.edu.ua (timetable.cgi)
        │  читає, коли сервер живий
        ▼
  sync.py ──► data/ (JSON) ──► GitHub-репозиторій ──► CDN (jsDelivr)
        ▲                                                    │
        │ GitHub Actions запускає кожні 2 години             │ читають
        │ (безкоштовно, без вашого комп'ютера)               ▼
                                              Telegram-бот (Cloudflare Workers)
                                              Сайт (Cloudflare Pages / GitHub Pages)
```

* **Синхронізатор** (`sync/`) знімає розклад із сайту університету й кладе
  його у вигляді компактних JSON-файлів у каталог `data/`.
* **GitHub Actions** (`.github/workflows/sync.yml`) запускає синхронізатор
  автоматично кожні 2 години вдень. Якщо сервер університету недоступний —
  запуск просто пропускається, а дзеркало лишається з останніми вдалими даними.
* **Telegram-бот** (`worker/`) працює на Cloudflare Workers (безкоштовний
  план) і читає лише дзеркало — тому відповідає 24/7.
* **Сайт** (`site/`) — статична сторінка, яка читає те саме дзеркало.

Ваш MacBook після первинного налаштування **більше не потрібен** для роботи
системи — усе виконується в хмарі.

## Склад проєкту

| Каталог / файл | Призначення |
|---|---|
| `ІНСТРУКЦІЯ-ЗАПУСКУ-САЙТУ.md` | **Покроковий запуск сайту в Інтернеті** |
| `sync/` | Синхронізатор: `sync.py`, клієнт сайту `timetable.py` |
| `data/` | Згенероване дзеркало (оновлюється автоматично) |
| `worker/` | Telegram-бот для Cloudflare Workers + `schema.sql` |
| `site/` | Статичний сайт-дзеркало (`index.html`, лише читання) |
| `.github/workflows/` | Автозапуск синхронізації |

## Крок 0. Безпека токена бота (обов'язково!)

Токен, який лежав у `config.py` старого бота, був переданий третім особам
(у т.ч. через цей чат) і вважається скомпрометованим:

1. Відкрийте @BotFather у Telegram → `/mybots` → оберіть бота →
   **API Token** → **Revoke current token**.
2. Новий токен нікуди не вписуйте у файли — він задасться як секрет
   Cloudflare на кроці 3.

## Крок 1. GitHub-репозиторій із дзеркалом

1. Створіть на GitHub **публічний** репозиторій, наприклад `rozklad-mirror`.
   (Публічний — бо дані з нього читаються без авторизації; розклад і так
   публічно доступний на сайті університету.)
2. Завантажте вміст цього пакета в репозиторій — через вебінтерфейс
   (Add file → Upload files) або git:

   ```bash
   git init && git add -A && git commit -m "Дзеркало розкладу: старт"
   git branch -M main
   git remote add origin git@github.com:ВАШ_ЛОГІН/rozklad-mirror.git
   git push -u origin main
   ```

3. Каталог `data/` уже містить свіжий знімок — бот і сайт можна
   налаштовувати одразу.

## Крок 2. Автосинхронізація (GitHub Actions)

Нічого налаштовувати не треба: файл `.github/workflows/sync.yml` уже в
репозиторії. Вкладка **Actions** покаже запуски кожні 2 години; кнопка
**Run workflow** — ручне оновлення поза розкладом.

За бажанням запускати синхронізацію вручну з будь-якого комп'ютера:

```bash
cd sync
pip install -r requirements.txt
python3 sync.py --out ../data        # знімок у data/
git add ../data && git commit -m "sync" && git push
```

Корисні опції `sync.py`: `--from/--to` (явний горизонт), `--groups all`
(усі групи факультетського довідника, не лише кафедра), `--only "43ПОцт"`
(точкове оновлення). Докладно — у docstring файла `sync/sync.py`.

## Крок 3. Telegram-бот на Cloudflare Workers

Потрібен безкоштовний акаунт Cloudflare і встановлений Node.js.

```bash
cd worker
npm install -g wrangler
npx wrangler login
```

1. **База даних** (стан діалогів і користувачі):
   ```bash
   npx wrangler d1 create rozklad-bot-db
   # скопіюйте виданий database_id у wrangler.toml (поле database_id)
   npx wrangler d1 execute rozklad-bot-db --file=schema.sql --remote
   ```
2. **Налаштування** в `wrangler.toml`:
   * `ADMIN_USERNAME`, `ADMIN_IDS` (свій ID дізнаєтеся командою /admin);
   * `DATA_BASE` — замініть `USER/REPO` на ваш репозиторій:
     `https://cdn.jsdelivr.net/gh/USER/REPO@main/data`;
   * `SETUP_KEY` — довгий випадковий рядок.
3. **Секрети**:
   ```bash
   npx wrangler secret put BOT_TOKEN    # новий токен від @BotFather
   npx wrangler secret put TG_SECRET    # довільний довгий випадковий рядок
   ```
4. **Деплой і реєстрація вебхука**:
   ```bash
   npx wrangler deploy
   # відкрийте у браузері (підставте свій SETUP_KEY і адресу воркера):
   # https://rozklad-bot.<ваш-акаунт>.workers.dev/setup?key=SETUP_KEY
   ```
   У відповідь має прийти `{"webhook": ..., "telegram": {"ok": true, ...}}`.
5. Напишіть боту `/start` — усе має працювати. Команда `/admin` покаже
   ваш числовий ID — додайте його в `ADMIN_IDS` і зробіть повторний deploy.

## Крок 4. Сайт

**Детальна покрокова інструкція запуску сайту в Інтернеті — у файлі
[`ІНСТРУКЦІЯ-ЗАПУСКУ-САЙТУ.md`](ІНСТРУКЦІЯ-ЗАПУСКУ-САЙТУ.md)** (написана для
людини без досвіду програмування: реєстрація GitHub → завантаження файлів
через GitHub Desktop → автосинхронізація → GitHub Pages).

Коротко: файл `site/index.html` самодостатній (дані читає з `./data`).
Найпростіший варіант — **GitHub Pages**: Settings → Pages → Source:
`main` / root. Сайт буде доступний за адресою
`https://USER.github.io/REPO/site/` — каталог `data/` поруч уже є.
У `site/index.html` зверху є константа `DATA_BASE` — якщо сайт і дані
розділені, пропишіть туди адресу дзеркала (jsDelivr).

Сайт працює **лише на читання**: він показує розклад точно так, як його
віддає офіційний електронний розклад університету. Жодної авторизації,
редагування чи внесення посилань на сайті немає.

## Експлуатація: що важливо знати

* **Під час блекауту** бот і сайт показують останній знімок із чесною
  позначкою «Дані станом на …»; якщо знімку понад 30 годин — з'являється
  попередження про застарілість.
* **Горизонт дзеркала** — весь навчальний рік: від 1 вересня поточного
  навчального року і на 75 днів уперед від дати синхронізації (змінюється
  параметрами `--from/--to/--past-days/--future-days`). Дата початку
  «котиться» автоматично: 1 вересня 2027 року дзеркало перейде на новий
  навчальний рік. Запити поза горизонтом повертатимуть «занять немає»
  з підказкою про межі.
* **Охоплення:** дзеркало синхронізує **усіх викладачів (~1170) і всі
  групи (~835) університету** — параметри `--faculty 0 --groups all`
  уже прописані в `.github/workflows/sync.yml`. Повна синхронізація
  триває ~1–1,5 год; якщо захочете лише кафедру (швидше) — приберіть
  ці прапорці з workflow. Миттєвого оновлення з сайту немає — натомість
  знімок, який не падає разом із сервером.
* **Ліміти безкоштовного Cloudflare:** 100 000 запитів Workers на день —
  для кафедри це з великим запасом. Розсилка оголошень з адмін-панелі
  розрахована на сотні користувачів (Telegram обмежує ~30 повідомлень/с).
* **Приватність:** дзеркало містить ПІБ викладачів у тому самому вигляді,
  що й публічний сайт розкладу університету. Якщо університет вирішить
  обмежити доступ — сайт можна заховати за Cloudflare Access, а бота
  лишити як є.
* **Сайт — лише читання:** за рішенням кафедри з сайту повністю прибрано
  авторизацію та внесення посилань викладачами — він відображає виключно
  те, що є в офіційному електронному розкладі. (У `worker/` лишилися
  відповідні API-endpoint'и — вони просто не використовуються сайтом;
  за потреби їх можна видалити, на роботу бота це не впливає.)

## Вартість

Усе працює на безкоштовних тарифах: GitHub (репозиторій + Actions),
Cloudflare (Workers + D1 + Pages), jsDelivr CDN. Жодних платежів і жодного
власного сервера.
